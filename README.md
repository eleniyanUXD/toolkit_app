# 🧰 Toolkit App

A Flutter-powered productivity app that brings everyday tools together in one place.

## ✨ Features

- 🔐 **Authentication** — Sign up and sign in with Supabase
- 🤖 **AI Assistant** — Get quick answers to everyday questions
- 💱 **Currency Converter** — Check currency exchange rates
- 📏 **Unit Converter** — Convert length, weight, volume, temperature, time, area, speed, and data
- 🧮 **Calculator** — Perform everyday calculations
- 📅 **Date Calculator** — Work with dates and date differences
- 📝 **Notes** — Create and manage notes
- 🕘 **Recent Activity** — View recent actions in the app

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Backend & Authentication:** Supabase
- **APIs:** Frankfurter API for currency exchange rates
- **AI:** Gemini through a Supabase Edge Function
- **Tools:** Git, GitHub, VS Code, Android Studio

## 📱 About This Project

Toolkit App was built as a hands-on project to improve my Flutter development skills and explore building practical mobile applications.

It demonstrates:

- UI design and reusable widgets
- Navigation between screens
- State management and data handling
- Authentication with Supabase
- API integration
- Organizing app features into separate screens and services

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- An editor such as VS Code or Android Studio

### Clone the repository

```bash
git clone https://github.com/eleniyanUXD/toolkit_app.git
cd toolkit_app
```

### Install dependencies

```bash
flutter pub get
```

### Run the app

```bash
flutter run
```

**Configuration:** Features that use Supabase or external API credentials may require environment variables and project configuration. Never commit private API keys or secrets to GitHub.
